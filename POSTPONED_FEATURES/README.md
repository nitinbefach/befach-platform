# Postponed Features

**Purpose:** Documentation of deferred features and conditions for reactivation.  
**Last Updated:** November 27, 2025  
**Maintenance:** Product Manager

## Overview

This folder tracks features that are NOT being built right now, including the reasons for postponement and conditions under which they should be reconsidered.

## Postponed Feature Template

```markdown
# Feature: [Name]

**Status:** POSTPONED
**Original Phase:** [Phase number]
**Postponed Date:** [Date]

## Reason for Postponement
[Why this feature was deferred]

## Condition to Reactivate
- [ ] Condition 1
- [ ] Condition 2

## Estimated Timeline for Reconsideration
[Date or milestone]

## Dependencies
[What this feature depends on]
```

## Why Track This

- Communicates long-term vision to team
- Clarifies why something isn't being built
- Defines conditions for reactivation
- Prevents infinite discussions about features
