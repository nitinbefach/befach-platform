## How to Use This Directory

1. **Before implementing a new library**, check if documentation exists here
2. **When learning a new tool**, refer to the comprehensive guides
3. **For quick lookups**, use the quick-ref files
4. **Add new tools** as you discover and use them in the project

## Adding New Tools

When adding a new tool or library:
1. Create a comprehensive documentation file in the appropriate subdirectory
2. Include installation instructions, basic usage, and common patterns
3. Consider creating a quick-ref companion file for frequently needed info
4. Update this README with the new addition
