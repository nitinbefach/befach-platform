# Architecture Documentation

**Purpose:** Comprehensive documentation of system design, database schemas, and architectural decisions.  
**Last Updated:** November 27, 2025  
**Maintenance:** Tech Lead

## Overview

This folder contains all architecture diagrams, schemas, and design documentation for the Befach platform.

## Key Files

- `System_Overview.md` - High-level system architecture
- `Technical_Documentation.md` - Detailed technical specifications
- `Frontend_Architecture.md` - Next.js app structure and components
- `Backend_Architecture.md` - Express.js API structure
- `Database_Schema.md` - Data structure and relationships
- `API_Design.md` - API endpoints and structure
- `Data_Flow_Diagram.md` - How data moves through the system
- `Integration_Points.md` - External service connections

## When to Use This Folder

- When designing new features that affect system architecture
- When onboarding new team members
- When making decisions about technology choices
- When documenting database changes
