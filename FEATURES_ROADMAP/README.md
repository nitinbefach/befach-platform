## Feature Document Template

Each feature file should include:
- Description
- User stories
- Acceptance criteria
- Dependencies
- Estimated effort
- Priority level

## When to Use This Folder

- When planning new features
- When writing feature specifications
- When prioritizing the backlog
- When estimating development effort
